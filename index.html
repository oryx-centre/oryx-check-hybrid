How it works

  1. On-device triage — Gemini Nano. The claim gets an instant first-pass verdict in your browser, via Firebase AI Logic. Nothing leaves your device for this step.
  2. Cloud evidence check — Gemini 2.5 Flash. The same claim is checked against the source text you provided. The model must quote the exact passage that supports or contradicts the claim — the evidence is shown, not asserted.
  3. Check card. Both verdicts side by side, the quoted passage, and a plain-English summary. Copy it, or come back to it in the history below.

The verdict taxonomy — Verified, Broken, Unverifiable, Title mismatch — comes from Oryx's published research: the 194-citation audit of AI governance claims (DOI 10.5281/zenodo.23731235) and the 66-citation study (DOI 10.5281/zenodo.23718472). The 10 demo claims are real claims from those audits, with the audit's own verdict shown separately from the model's live verdicts.

Built with Firebase AI Logic (Gemini Developer API backend): on-device inference uses the Prompt API in Chrome on Desktop v139+; the cloud check uses Gemini 2.5 Flash. No accounts, no login. Check history is stored anonymously in Firestore (or locally in your browser if Firestore is unavailable) and contains no personal information.
